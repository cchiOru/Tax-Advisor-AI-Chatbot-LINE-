# แหล่งอ้างอิงของระบบ

บรรณานุกรมกลางของโครงงาน รวมทุกแหล่งข้อมูลที่นำเข้าสู่ระบบ เครื่องมือที่ใช้ และงานวิจัยที่อ้างถึง

**กติกาการดูแลไฟล์นี้**
ทุกครั้งที่นำข้อมูลชุดใหม่เข้าระบบ ต้องบันทึกแหล่งที่มาไว้ในไฟล์นี้ก่อนเสมอ
ข้อมูลที่ถูกลบออกจากระบบภายหลังยังคงบันทึกไว้ในหัวข้อ "ข้อมูลที่เคยนำเข้าแต่เลิกใช้"
เพื่อให้ตรวจสอบย้อนกลับได้ว่าเคยพิจารณาแหล่งใดมาบ้างและเลิกใช้เพราะเหตุใด

ปรับปรุงล่าสุด 5 สิงหาคม 2569

**ข้อจำกัดที่ต้องระบุ** ตารางนี้ใช้อ้างถ้อยคำของกฎหมายเท่านั้น ห้ามนำตัวเลขในตัวบท
ไปตอบคำถามจำนวนเงิน เพราะหลายมาตราถูกแก้ไขโดยกฎหมายลำดับรองภายหลัง

หน้าบัญชีอัตราภาษีเงินได้ได้ 0 มาตรา เพราะเป็นตารางอัตรา ไม่ได้เขียนในรูปมาตรา
เนื้อหาส่วนนี้อยู่ในฐานความรู้และในเครื่องคำนวณอยู่แล้ว

## 7. ข้อมูลที่เคยนำเข้าแต่เลิกใช้

**Open Law Data Thailand ชุด `ocs-krisdika`**
https://huggingface.co/open-law-data-thailand · https://www.openlawdatathailand.org
สัญญาอนุญาต CC-BY 4.0 · นำเข้าไว้ในตาราง `revenue_code_sections` จำนวน 15,441 มาตรา

**เหตุผลที่เลิกใช้** ตรวจสอบแล้วพบว่าเป็นประมวลรัษฎากรฉบับ พ.ศ. 2482
คือตัวบทดั้งเดิมที่ยังไม่ผ่านการแก้ไข ทุกระเบียนมีวันที่ประกาศ 1 เมษายน 2482
ตัวเลขในนั้นล้าสมัยทั้งหมด เช่น ค้นคำว่า "ร้อยละ 50 แต่ต้องไม่เกิน 100,000" ไม่พบผลลัพธ์
จึงเปลี่ยนไปดึงตัวบทฉบับปัจจุบันจากเว็บไซต์กรมสรรพากรโดยตรงแทน

**ยังเก็บตารางนี้ไว้ในฐานข้อมูล** เพื่อเป็นหลักฐานประกอบกระบวนการคัดเลือกแหล่งข้อมูล
ในบทที่ 3 ของปริญญานิพนธ์ แต่ระบบไม่ได้ใช้ตอบคำถามผู้ใช้
