# ประกาศความเป็นส่วนตัว

ระบบที่ปรึกษาด้านภาษีด้วยปัญญาประดิษฐ์บนไลน์ ("คุณภาษี")

ฉบับที่ 1.0 · มีผลตั้งแต่ 6 สิงหาคม 2569

---

## เอกสารนี้คืออะไร

ระบบนี้เก็บข้อมูลส่วนบุคคลของผู้ใช้ จึงต้องแจ้งให้ทราบว่าเก็บอะไร เก็บไปทำอะไร
เก็บนานแค่ไหน และผู้ใช้มีสิทธิอะไรบ้าง ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

ข้อความที่ผู้ใช้เห็นในแอป LINE เป็นฉบับย่อ เอกสารนี้คือฉบับเต็ม

---

## ข้อมูลที่เก็บ

| ข้อมูล | เก็บจากไหน | เก็บไว้ที่ |
|---|---|---|
| รหัสผู้ใช้ LINE | LINE Messaging API | ตาราง `users` |
| ชื่อที่แสดงในบัญชี LINE | LINE Profile API | ตาราง `users` |
| รูปโปรไฟล์และข้อความสถานะ | LINE Profile API | ตาราง `users` |
| ข้อความที่ผู้ใช้พิมพ์ | ผู้ใช้พิมพ์เอง | ตาราง `conversations` และ `n8n_chat_histories` |
| คำตอบที่ระบบตอบกลับ | ระบบสร้างขึ้น | ตาราง `conversations` และ `n8n_chat_histories` |
| เวลาที่ระบบใช้ตอบ ประเภทคำถาม และรายการความรู้ที่ค้นเจอ | ระบบบันทึกเอง | ตาราง `conversations` |

**ระบบไม่ขอและไม่เก็บ** เลขประจำตัวประชาชน เลขบัญชีธนาคาร ที่อยู่ เบอร์โทรศัพท์
หรือเอกสารทางภาษีใด ๆ ถ้าผู้ใช้พิมพ์ข้อมูลเหล่านี้เข้ามาเอง ระบบจะเก็บไปพร้อมกับข้อความ
จึงไม่ควรพิมพ์ข้อมูลที่ไม่จำเป็นเข้ามา

---

## วัตถุประสงค์ของการเก็บ

**1. ให้ระบบจำบทสนทนาก่อนหน้าได้**
ผู้ใช้จะถามต่อเนื่องได้ เช่นถามเรื่องภาษีแล้วถามต่อว่า "แล้วถ้ามีบุตร 2 คนล่ะ"
โดยไม่ต้องพิมพ์เงื่อนไขเดิมซ้ำ ระบบใช้บทสนทนา 10 ข้อความล่าสุดเป็นบริบท

**2. นำไปปรับปรุงคำตอบให้ดีขึ้น**
วิเคราะห์ว่าคำถามประเภทใดที่ระบบตอบได้ไม่ดี ฐานข้อมูลขาดเรื่องอะไร
และคำตอบใช้เวลานานเกินไปหรือไม่ แล้วนำไปแก้ไขระบบ

ระบบ **ไม่ใช้ข้อมูลเพื่อโฆษณา ไม่ขาย และไม่ส่งต่อให้บุคคลภายนอก**

---

## การขอความยินยอมและผลของการปฏิเสธ

ระบบขอความยินยอมตอนผู้ใช้กดเพิ่มเพื่อนครั้งแรก โดยแสดงข้อความอธิบายพร้อมปุ่มให้เลือก
สองปุ่มคือ ยินยอม และ ไม่ยินยอม

| สถานะ | ระบบตอบคำถามให้ | เก็บข้อความ | จำบทสนทนาก่อนหน้า |
|---|---|---|---|
| ยินยอม | ได้ | เก็บ | จำได้ |
| ไม่ยินยอม | ได้ครบทุกอย่างเหมือนเดิม | ไม่เก็บ | จำไม่ได้ |
| ยังไม่ตอบ | ได้ครบทุกอย่างเหมือนเดิม | ไม่เก็บ | จำไม่ได้ |

**การปฏิเสธไม่ทำให้ใช้งานไม่ได้** ผู้ใช้ยังถามคำถามและได้คำตอบครบถ้วนเหมือนกันทุกประการ
สิ่งเดียวที่ต่างคือระบบจะจำบทสนทนาก่อนหน้าไม่ได้ จึงต้องพิมพ์เงื่อนไขให้ครบในคำถามเดียว

เหตุผลที่ออกแบบแบบนี้คือ ความยินยอมต้องให้โดยอิสระ ถ้าปฏิเสธแล้วใช้งานไม่ได้
ก็ไม่ถือว่าเป็นความยินยอมที่สมบูรณ์

**ผู้ที่ยังไม่ตอบ ระบบถือว่ายังไม่ได้รับความยินยอม** และจะไม่เก็บข้อความ
เพราะการนิ่งเฉยไม่ถือเป็นการให้ความยินยอม

---

## สิทธิของผู้ใช้ และวิธีใช้สิทธิ

| สิทธิ | วิธีใช้ |
|---|---|
| ถอนความยินยอมและขอลบข้อมูล | พิมพ์ว่า **ลบข้อมูลของฉัน** |
| กลับมาให้เก็บข้อมูลอีกครั้ง | พิมพ์ว่า **ขอเก็บข้อมูลได้** |
| ขอดูข้อมูลที่ระบบเก็บไว้ | ติดต่อผู้จัดทำระบบ |

เมื่อพิมพ์ว่าลบข้อมูลของฉัน ระบบจะลบทั้งประวัติการสนทนาในตาราง `conversations`
และบทสนทนาที่ระบบจำไว้ในตาราง `n8n_chat_histories` ทันที แล้วตอบยืนยันกลับ
จากนั้นสถานะจะเปลี่ยนเป็นไม่ยินยอม ระบบจะไม่เก็บข้อความใหม่อีก

คำที่ใช้ได้ยังรวมถึง ลบข้อมูลของผม · ถอนความยินยอม · ลบข้อมูล

---

## ระยะเวลาการเก็บและการเข้าถึง

ข้อมูลเก็บไว้ตลอดระยะเวลาที่จัดทำและนำเสนอปริญญานิพนธ์ หลังจากนั้นจะลบทั้งหมด

ฐานข้อมูลติดตั้งอยู่บนเครื่องคอมพิวเตอร์ของผู้จัดทำ ไม่ได้อยู่บนบริการคลาวด์สาธารณะ
เข้าถึงได้เฉพาะผู้จัดทำโครงงานเท่านั้น

ข้อความของผู้ใช้จะถูกส่งไปยัง Google Gemini เพื่อสร้างคำตอบ ซึ่งเป็นบริการภายนอก
การส่งนี้เป็นส่วนหนึ่งของการทำงานของระบบ ไม่ใช่การเปิดเผยข้อมูลเพื่อวัตถุประสงค์อื่น

---

## ข้อจำกัดที่ผู้ใช้ควรทราบ

ระบบนี้เป็นผลงานการศึกษา ไม่ใช่บริการเชิงพาณิชย์ และไม่ใช่บริการของกรมสรรพากร
คำตอบเป็นข้อมูลเบื้องต้นเท่านั้น ไม่ใช่คำวินิจฉัยทางกฎหมายหรือทางภาษี
ควรตรวจสอบกับกรมสรรพากรหรือผู้เชี่ยวชาญก่อนนำไปใช้ตัดสินใจจริงเสมอ

---

## การเปลี่ยนแปลงเอกสารนี้

ระบบบันทึกไว้ว่าผู้ใช้แต่ละคนให้ความยินยอมกับเอกสารฉบับใด ในคอลัมน์ `consent_version`

ถ้าแก้ไขวัตถุประสงค์หรือขอบเขตข้อมูลที่เก็บในสาระสำคัญ จะเพิ่มเลขฉบับ
และขอความยินยอมใหม่จากผู้ใช้ทุกคน ไม่ถือว่าความยินยอมเดิมครอบคลุมถึงเงื่อนไขใหม่

---

## ผู้จัดทำและผู้ควบคุมข้อมูล

นายยศกร แจ้งมณี และนางสาวณัฏฐณิชา ป้องป้อม
ภาควิชาวิทยาการคอมพิวเตอร์และเทคโนโลยีสารสนเทศ คณะวิทยาศาสตร์ มหาวิทยาลัยนเรศวร

อาจารย์ที่ปรึกษา ผู้ช่วยศาสตราจารย์ ดร.สัญญา เครือหงษ์
