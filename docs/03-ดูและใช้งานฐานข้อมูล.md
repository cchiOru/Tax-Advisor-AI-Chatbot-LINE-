# คู่มือเข้าดูฐานข้อมูลของระบบ

มีสองวิธี เลือกใช้ตามความถนัด

| วิธี | เหมาะกับ | ต้องติดตั้งเพิ่ม |
|---|---|---|
| pgAdmin (หน้าจอเว็บ) | ดูข้อมูลเป็นตาราง คลิกดูโครงสร้าง เขียนคำสั่งแล้วเห็นผลทันที | ไม่ต้อง |
| คำสั่ง psql | ดึงตัวเลขเร็วๆ คัดลอกผลไปใส่รายงาน | ไม่ต้อง |

## วิธีที่ 1: pgAdmin (แนะนำ)

### เปิดใช้งาน

```powershell
cd D:\project
docker compose --profile tools up -d pgadmin
```

ครั้งแรกจะดาวน์โหลดประมาณ 500 MB ใช้เวลาสักครู่ ครั้งถัดไปเปิดได้ทันที

### เข้าใช้งาน

1. เปิดเบราว์เซอร์ไปที่ **http://localhost:5050**
2. ล็อกอินด้วย

   | ช่อง | ค่า |
   |---|---|
   | Email | `admin@taxadvisor.local` |
   | Password | `admin1234` |

   (เปลี่ยนได้โดยเพิ่ม `PGADMIN_EMAIL` และ `PGADMIN_PASSWORD` ในไฟล์ `.env`)

3. ในแถบซ้ายจะเห็นเซิร์ฟเวอร์ตั้งไว้ให้แล้ว 2 รายการ คลิกที่ **Tax Advisor - ฐานข้อมูลระบบ**
4. ระบบจะถามรหัสผ่านของฐานข้อมูล ให้ใส่ค่า `POSTGRES_PASSWORD` จากไฟล์ `.env`
   ติ๊ก **Save Password** ไว้ด้วย จะได้ไม่ต้องกรอกซ้ำ

### ดูข้อมูลในตาราง

ในแถบซ้าย ไล่ตามลำดับนี้

```
Tax Advisor - ฐานข้อมูลระบบ
└── Databases
    └── tax_advisor
        └── Schemas
            └── public
                ├── Tables       ← ตารางข้อมูล
                └── Views        ← มุมมองสำเร็จรูปสำหรับวิเคราะห์
```

คลิกขวาที่ชื่อตาราง เลือก **View/Edit Data → All Rows** เพื่อดูข้อมูลทั้งหมด

### เขียนคำสั่งเอง

กดเมนู **Tools → Query Tool** แล้วพิมพ์คำสั่ง กด **F5** เพื่อรัน

### ปิดเมื่อไม่ใช้

```powershell
docker compose stop pgadmin
```

pgAdmin กินหน่วยความจำพอสมควร ปิดไว้เมื่อไม่ได้ใช้จะทำให้เครื่องทำงานได้ลื่นขึ้น
โดยเฉพาะตอนรัน Typhoon ที่ต้องใช้ทรัพยากรมาก

## วิธีที่ 2: คำสั่ง psql

### เข้าโหมดโต้ตอบ

```powershell
docker exec -it tax-advisor-postgres psql -U n8n_admin -d tax_advisor
```

เมื่อเข้าได้แล้ว เครื่องหมายจะเปลี่ยนเป็น `tax_advisor=#`

| คำสั่ง | ความหมาย |
|---|---|
| `\dt` | ดูรายชื่อตารางทั้งหมด |
| `\dv` | ดูรายชื่อ view ทั้งหมด |
| `\d ชื่อตาราง` | ดูโครงสร้างของตาราง |
| `\x` | สลับการแสดงผลเป็นแนวตั้ง (อ่านง่ายเมื่อข้อมูลยาว) |
| `\q` | ออกจากโปรแกรม |

### รันคำสั่งเดียวแล้วออกเลย

```powershell
docker exec -it tax-advisor-postgres psql -U n8n_admin -d tax_advisor -c "คำสั่ง SQL"
```

## ตารางและมุมมองที่มีในระบบ

### ตารางข้อมูล

| ตาราง | เก็บอะไร |
|---|---|
| `users` | ผู้ใช้ที่ทักเข้ามาทาง LINE |
| `conversations` | ประวัติการสนทนา พร้อมเวลาตอบสนองและผลการสืบค้น |
| `tax_law_knowledge` | ฐานข้อมูลสรุปที่เขียนให้คนอ่านเข้าใจง่าย 13 รายการ |
| `tax_deductions` | ตารางอ้างอิงค่าลดหย่อน |
| `revenue_code_sections` | ตัวบทกฎหมายจาก Open Law Data Thailand 15,441 ย่อหน้า |
| `n8n_chat_histories` | หน่วยความจำบทสนทนาที่ AI Agent ใช้ |

### มุมมองสำเร็จรูปสำหรับวิเคราะห์ผล

| มุมมอง | ให้ข้อมูลอะไร |
|---|---|
| `v_response_time_stats` | เวลาตอบสนอง ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน มัธยฐาน เปอร์เซ็นไทล์ที่ 95 |
| `v_retrieval_stats` | อัตราการสืบค้นฐานข้อมูลสำเร็จ |
| `v_daily_usage` | จำนวนผู้ใช้และคำถามรายวัน |
| `v_law_sections` | ตัวบทกฎหมายรายมาตราที่รวมย่อหน้าแล้ว |
| `v_revenue_code` | ประมวลรัษฎากร 281 มาตรา ตัวบทเต็ม |

## คำสั่งที่ใช้บ่อยสำหรับเก็บข้อมูลลงรายงาน

### ดูบทสนทนาล่าสุด

```sql
SELECT id, role, LEFT(message, 60) AS ข้อความ,
       response_time_ms, knowledge_hits, model_name, created_at
FROM conversations
ORDER BY id DESC
LIMIT 20;
```

### สถิติเวลาตอบสนอง แยกตามแบบจำลอง

```sql
SELECT model_name AS แบบจำลอง,
       COUNT(*) AS จำนวนครั้ง,
       ROUND(AVG(response_time_ms)::numeric, 0) AS เฉลี่ย_ms,
       ROUND(STDDEV_SAMP(response_time_ms)::numeric, 0) AS ส่วนเบี่ยงเบน_ms,
       MIN(response_time_ms) AS ต่ำสุด,
       MAX(response_time_ms) AS สูงสุด
FROM conversations
WHERE role = 'assistant' AND response_time_ms IS NOT NULL
GROUP BY model_name
ORDER BY เฉลี่ย_ms;
```

ตารางนี้ใส่บทที่ 4 ได้โดยตรง

### อัตราการสืบค้นฐานข้อมูลสำเร็จ

```sql
SELECT * FROM v_retrieval_stats;
```

### คำถามที่ผู้ใช้ถามบ่อย (ใช้วิเคราะห์ความต้องการ)

```sql
SELECT message AS คำถาม, COUNT(*) AS จำนวนครั้ง
FROM conversations
WHERE role = 'user'
GROUP BY message
ORDER BY COUNT(*) DESC
LIMIT 20;
```

### ค้นตัวบทกฎหมายรายมาตรา

```sql
SELECT section_no AS มาตรา, LEFT(content, 200) AS เนื้อหา
FROM v_revenue_code
WHERE section_no = '40';
```

### ดูฐานข้อมูลที่ใช้ตอบคำถาม

```sql
SELECT category AS หมวด, title AS หัวข้อ, source AS แหล่งที่มา
FROM tax_law_knowledge
ORDER BY category;
```

## ส่งออกข้อมูลเป็นไฟล์ CSV เพื่อวิเคราะห์ใน Excel

```powershell
docker exec tax-advisor-postgres psql -U n8n_admin -d tax_advisor -c "\copy (SELECT * FROM conversations ORDER BY id) TO STDOUT WITH CSV HEADER" > backup\conversations.csv
```

> ไฟล์ที่ได้เป็น UTF-8 หากเปิดใน Excel แล้วภาษาไทยเพี้ยน
> ให้ใช้เมนู Data → From Text/CSV แล้วเลือก File Origin เป็น **65001: Unicode (UTF-8)**

## สำรองฐานข้อมูลทั้งหมด

```powershell
docker exec tax-advisor-postgres pg_dumpall -U n8n_admin -f /tmp/backup.sql
docker cp tax-advisor-postgres:/tmp/backup.sql backup\backup.sql
```

> อย่าใช้เครื่องหมาย `>` เปลี่ยนทิศทางไฟล์โดยตรง
> เพราะ Windows PowerShell จะบันทึกเป็นรหัสอักขระ UTF-16 ซึ่งกู้คืนไม่ได้
