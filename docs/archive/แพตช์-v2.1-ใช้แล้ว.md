# แพตช์ v2.1 — แก้การสืบค้นฐานความรู้และการบันทึกชื่อแบบจำลอง

> ใช้แทนการ import workflow ใหม่ จะได้ไม่ต้องผูก credential ใหม่ทั้ง 5 ตัว
> แก้ 2 node เท่านั้น ใช้เวลาประมาณ 3 นาที

## ปัญหาที่แพตช์นี้แก้

| อาการ | สาเหตุ |
|---|---|
| `knowledge_hits` เป็น 0 ทุกครั้ง ระบบไม่เคยค้นเจอข้อมูลเลย | Full-Text Search ของ PostgreSQL ตัดคำภาษาไทยไม่ได้ และ `plainto_tsquery` บังคับให้ทุกคำต้องปรากฏพร้อมกัน |

## จุดที่ 1: node "Search Tax Knowledge"

ดับเบิลคลิกเปิด node แล้วแก้ 2 ช่อง

### ช่อง Query — ลบของเดิมทั้งหมด แล้ววางอันนี้แทน

```sql
WITH kws AS (
  SELECT unnest(string_to_array($1, '|')) AS k
),
scored AS (
  SELECT
    t.category,
    t.title,
    t.content,
    t.source,
    (SELECT count(*) FROM kws
     WHERE coalesce(t.category,'') || ' ' || coalesce(t.title,'') || ' ' || coalesce(t.content,'')
           ILIKE '%' || kws.k || '%') AS score
  FROM tax_law_knowledge t
)
SELECT category, title, content, source, score
FROM scored
WHERE score > 0
ORDER BY score DESC, category
LIMIT 3;
```

## จากนั้น

1. กด **Ctrl+S** บันทึก
2. กด **Publish** ให้ขึ้นสถานะสีเขียว
3. ทดสอบใน LINE ด้วยคำถามเดิม

```
ผมมีรายได้จากธุรกิจส่วนตัวปีละ 2000000 บาท มีคู่สมรสไม่มีรายได้ และลูก 2 คน ภาษีที่ต้องชำระเท่าไหร่
```

คำตอบที่ถูกต้องคือ **45,500 บาท**

4. ตรวจสอบผล

```powershell
docker exec -it tax-advisor-postgres psql -U n8n_admin -d tax_advisor -c "SELECT id, role, response_time_ms, knowledge_hits, model_name, LEFT(matched_knowledge,60) AS matched FROM conversations ORDER BY id DESC LIMIT 2;"
```

ต้องได้ `knowledge_hits` มากกว่า 0 และ `model_name` เป็น `typhoon2.5-qwen3-4b`
