# คู่มือติดตั้งฉบับละเอียด (สำหรับคนที่ไม่เคยทำมาก่อนเลย)

คู่มือนี้อธิบายทุกคลิก ทุกขั้นตอน ตั้งแต่ศูนย์ ไม่ต้องมีความรู้เขียนโปรแกรมมาก่อน
ทำตามลำดับ 1 → 15 ห้ามข้าม

---

## ก่อนเริ่ม: ระบบนี้คืออะไร (อ่าน 1 นาที)

เราจะสร้างแชทบอทบน LINE ที่ตอบคำถามเรื่องภาษี โดยมี 3 ส่วนทำงานร่วมกัน:

1. **Docker** — โปรแกรมที่รันระบบทั้งหมดในเครื่องเรา (เหมือนกล่องที่บรรจุโปรแกรมย่อยๆ ไว้ข้างใน)
2. **n8n** — ตัวจัดการขั้นตอนการทำงาน (รับข้อความจาก LINE → ส่งให้ AI คิด → ตอบกลับ)
3. **ngrok** — ตัวเปิดทางให้ LINE (ที่อยู่บนอินเทอร์เน็ต) คุยกับเครื่องคอมของเรา (ที่ไม่มี public URL) ได้

สิ่งที่ต้องมี: คอมพิวเตอร์ Windows, อินเทอร์เน็ต, อีเมล, และบัญชี Google

ไม่ต้องใช้บัตรเครดิต ระบบใช้ Google Gemini ซึ่งมีโควตาฟรีให้ใช้ทดสอบเพียงพอ

---

## ขั้นตอนที่ 1: ตรวจสอบเครื่องคอมพิวเตอร์

1. กดปุ่ม **Start** (ธงวินโดวส์มุมล่างซ้าย) พิมพ์ว่า `winver` แล้วกด Enter
2. จะมีหน้าต่างเด้งขึ้นมาบอกเวอร์ชัน Windows ต้องเป็น **Windows 10 เวอร์ชัน 2004 ขึ้นไป** หรือ **Windows 11** (ถ้าเก่ากว่านี้ Docker Desktop จะติดตั้งไม่ได้ ต้องอัปเดต Windows ก่อน)
3. ปิดหน้าต่างนั้นไปได้เลย

---

## ขั้นตอนที่ 2: ติดตั้ง Docker Desktop

1. เปิดเบราว์เซอร์ (Chrome/Edge) ไปที่ https://www.docker.com/products/docker-desktop/
2. กดปุ่ม **Download for Windows** (ปุ่มสีฟ้า) ไฟล์จะโหลดชื่อประมาณ `Docker Desktop Installer.exe`
3. หลังโหลดเสร็จ ดับเบิลคลิกไฟล์นั้นเพื่อเริ่มติดตั้ง
4. จะมีหน้าต่างถามตัวเลือก ให้ติ๊กถูกทั้ง 2 ช่อง (Use WSL 2, Add desktop shortcut) แล้วกด **Ok**
5. รอสักครู่จนติดตั้งเสร็จ จะมีปุ่ม **Close and restart** ให้กด แล้วเครื่องจะรีสตาร์ท
6. หลังเครื่องเปิดใหม่ Docker Desktop จะเปิดขึ้นมาเอง (ถ้าไม่เปิด ให้กด Start พิมพ์ `Docker Desktop` แล้วกด Enter)
7. ครั้งแรกจะมีหน้าจอ Terms — กด **Accept**
8. ถ้าถามให้ล็อกอิน/สมัครบัญชี Docker Hub สามารถกด **Skip** ได้ (ไม่จำเป็นสำหรับงานนี้)
9. รอจนไอคอนวาฬที่มุมขวาล่างของจอ (system tray) หยุดกระพริบและขึ้นข้อความ "Docker Desktop is running" — แปลว่าพร้อมใช้งาน

### ตรวจสอบว่าติดตั้งสำเร็จ

1. กด Start พิมพ์ `PowerShell` เลือก **Windows PowerShell** เปิดขึ้นมา (จะเป็นหน้าจอสีน้ำเงินมีตัวอักษรขาว)
2. พิมพ์คำสั่งนี้แล้วกด Enter:
   ```
   docker --version
   ```
3. ถ้าขึ้นข้อความแบบ `Docker version 27.x.x, build xxxxx` แปลว่าสำเร็จ
4. อย่าเพิ่งปิด PowerShell (จะใช้ต่อ)

## ขั้นตอนที่ 3: สมัคร ngrok (ฟรี)

1. เปิดแท็บใหม่ในเบราว์เซอร์ ไปที่ https://dashboard.ngrok.com/signup
2. สมัครด้วยอีเมลหรือกด **Continue with Google** ก็ได้ (ง่ายสุด)
3. หลังสมัครเสร็จ ระบบจะพาไปหน้า Dashboard
4. ที่เมนูด้านซ้าย คลิก **Your Authtoken** (หรือไปที่ https://dashboard.ngrok.com/get-started/your-authtoken โดยตรง)
5. จะเห็นข้อความยาวๆ แบบ `2abcXYZ...` อยู่ในกล่อง ให้กดปุ่ม **Copy** ข้างๆ
6. เปิด Notepad (กด Start พิมพ์ `Notepad`) แล้ววางข้อความนี้เก็บไว้ชั่วคราว พร้อมเขียนกำกับว่า "ngrok token"

## ขั้นตอนที่ 4: สร้าง LINE Official Account

> ตั้งแต่ก.ย. 2024 เป็นต้นมา LINE เปลี่ยนขั้นตอน **สร้าง Messaging API channel ตรงๆ จาก Developers Console ไม่ได้แล้ว**
> ต้องไปสร้าง **LINE Official Account** ก่อน แล้วค่อยกลับมาเปิดใช้งาน Messaging API ทีหลัง ทำตามนี้:

### 4.1 สร้าง LINE Official Account

1. ไปที่ https://developers.line.biz/console/ แล้วกด **Log in** ล็อกอินด้วยบัญชี LINE ของคุณ
2. กด **Create new channel** จะเจอหน้าที่บอกว่าต้องสร้าง Official Account ก่อน (หน้าตาแบบในรูปที่ส่งมา) กดปุ่มสีเขียว **Create a LINE Official Account** (ปุ่มนี้จะพาไปเว็บอีกอันคือ LINE Official Account Manager/หน้าสมัคร OA)
3. กรอกฟอร์มสร้างบัญชี:
   - **Account name**: ชื่อบอท เช่น `ที่ปรึกษาภาษี AI` (ผู้ใช้จะเห็นชื่อนี้ใน LINE)
   - **Country/Region**: Thailand
   - **Industry / Category**: เลือกหมวดใกล้เคียง เช่น Finance
   - อีเมลและเบอร์โทร: ใส่ของคุณ แล้วกด **Verify** เพื่อรับรหัส OTP ทาง SMS กรอกรหัสยืนยัน
4. กด **Next / Create** จนเสร็จขั้นตอน จะได้ LINE Official Account ใหม่ 1 บัญชี

### 4.2 เปิดใช้งาน Messaging API ผ่าน LINE Official Account Manager

1. ไปที่ https://manager.line.biz/ แล้วล็อกอินด้วยบัญชีเดียวกับข้อ 4.1
2. เลือกบัญชี (Official Account) ที่เพิ่งสร้าง
3. คลิกไอคอนรูปเฟือง **Settings** มุมขวาบน
4. ในเมนูด้านซ้ายของหน้า Settings คลิก **Messaging API**
5. กดปุ่ม **Enable Messaging API**
6. เลือก Provider:
   - ถ้ายังไม่มี Provider ให้เลือก **New provider** แล้วตั้งชื่อ เช่น `TaxAdvisorProject`
   - ⚠️ ชื่อ Provider เปลี่ยน/ลบทีหลังไม่ได้ ตั้งให้เรียบร้อย
7. อ่านข้อตกลงแล้วกด **Agree** จากนั้นกด **Confirm/OK**
8. ระบบจะสร้าง Messaging API channel ให้อัตโนมัติ ผูกกับ Official Account นี้

### 4.3 กลับไปที่ LINE Developers Console

1. เปิด https://developers.line.biz/console/ อีกครั้ง (ล็อกอินบัญชีเดิม)
2. คลิกเข้า Provider ที่สร้างไว้ในข้อ 4.2 จะเห็น Channel ประเภท Messaging API ปรากฏอยู่แล้ว (ชื่อเดียวกับ Account name)
3. คลิกเข้าไปที่ Channel นั้น เพื่อไปทำขั้นตอนถัดไป (เอา Channel Secret/Access Token)

### เอา Channel Secret

1. คลิกเข้าไปที่ Channel ที่เพิ่งสร้าง
2. อยู่ที่แท็บ **Basic settings** (แท็บแรก)
3. เลื่อนหาคำว่า **Channel secret** จะเห็นรหัสยาวๆ กด **Copy** วางเก็บใน Notepad กำกับว่า "LINE Channel secret"

### เอา Channel Access Token

1. คลิกแท็บ **Messaging API** (แท็บที่ 3 ด้านบน)
2. เลื่อนลงมาหาหัวข้อ **Channel access token**
3. กดปุ่ม **Issue** เพื่อออก token
4. จะมีรหัสยาวๆ ปรากฏขึ้น กด **Copy** วางเก็บใน Notepad กำกับว่า "LINE Channel access token"

### ปิดฟีเจอร์ที่จะชนกับบอทเรา

ยังอยู่ในแท็บ **Messaging API** เลื่อนหา:
- **Auto-reply messages** → กด **Edit** ที่ LINE Official Account Manager แล้วปิด (Disabled)
- **Greeting messages** → ปิดเช่นกัน (Disabled)
- **Use webhook** → เปิดสวิตช์เป็น **On** (ยังใส่ URL ไม่ได้ตอนนี้ ข้ามไปก่อน จะกลับมาใส่ทีหลัง)

### เอา QR Code ไว้เพิ่มเพื่อน

ในแท็บ **Messaging API** เลื่อนขึ้นด้านบนจะเห็น QR Code ของบัญชี ให้จำหน้านี้ไว้ (จะใช้ตอนทดสอบท้ายสุด) หรือ**อย่าเพิ่งสแกนตอนนี้**

## ขั้นตอนที่ 5: เอา API Key ของ Google Gemini (ฟรี ไม่ต้องใช้บัตร)

1. ไปที่ https://aistudio.google.com/apikey แล้วล็อกอินด้วยบัญชี Google
2. กดปุ่ม **Create API key**
3. ถ้าถามให้เลือกโปรเจกต์ ให้เลือกอันไหนก็ได้ หรือกดสร้างใหม่
4. จะมีรหัสยาว ๆ ขึ้นต้นด้วย `AIza...` แสดงขึ้นมา กดปุ่มคัดลอก
5. วางเก็บใน Notepad กำกับว่า "Gemini API key"

> โควตาฟรีของ Gemini จำกัดจำนวนคำขอต่อนาทีและต่อวัน ใช้ทดสอบและสาธิตเพียงพอ
> แต่ถ้าถามรัวเกินไปจะขึ้นข้อผิดพลาด 429 ให้รอสักครู่แล้วลองใหม่

## ขั้นตอนที่ 6: ตั้งค่าไฟล์ `.env`

1. เปิด **File Explorer** (ไอคอนโฟลเดอร์บน Taskbar) ไปที่ `D:\project`
2. จะเห็นไฟล์ชื่อ `.env.example` — คลิกขวาที่ไฟล์นี้ เลือก **Copy**
3. คลิกขวาที่พื้นที่ว่างในโฟลเดอร์เดียวกัน เลือก **Paste** จะได้ไฟล์ชื่อ `.env.example - Copy`
4. คลิกขวาไฟล์ที่ก๊อปมา เลือก **Rename** เปลี่ยนชื่อเป็น `.env` (ลบตัว `.example` ออก และลบคำว่า " - Copy" ออกด้วย ให้เหลือแค่ `.env`)
   - ถ้า Windows ถามยืนยันเปลี่ยนนามสกุลไฟล์ ให้กด **Yes**
   - ถ้ามองไม่เห็นนามสกุลไฟล์ ให้ไปที่แท็บ **View** ด้านบนของ File Explorer ติ๊ก **File name extensions** ก่อน
5. คลิกขวาไฟล์ `.env` เลือก **Open with → Notepad**
6. จะเห็นบรรทัดค่าต่างๆ ให้แก้ไขทีละบรรทัดตามนี้ (แทนที่ข้อความหลังเครื่องหมาย `=`):

   | บรรทัดในไฟล์ | ใส่อะไร |
   |---|---|
   | `POSTGRES_PASSWORD=` | ตั้งรหัสผ่านเอง เช่น `MyStrongPass123` |
   | `N8N_ENCRYPTION_KEY=` | ดูวิธีสร้างค่านี้ด้านล่าง (ข้อ 7) |
   | `NGROK_AUTHTOKEN=` | วางค่าจาก Notepad "ngrok token" (ขั้นตอนที่ 3) |
   | `LINE_CHANNEL_ACCESS_TOKEN=` | วางค่าจาก Notepad "LINE Channel access token" |
   | `LINE_CHANNEL_SECRET=` | วางค่าจาก Notepad "LINE Channel secret" |
   | `GEMINI_API_KEY=` | วางค่าจาก Notepad "Gemini API key" |

   บรรทัดอื่นๆ (`POSTGRES_USER`, `POSTGRES_DB`, `N8N_PORT` ฯลฯ) **ไม่ต้องแก้** ปล่อยค่าเริ่มต้นไว้ได้เลย

7. สร้างค่า `N8N_ENCRYPTION_KEY`:
   - กลับไปที่ PowerShell ที่เปิดค้างไว้ (ขั้นตอนที่ 2)
   - พิมพ์คำสั่งนี้แล้ว Enter:
     ```
     -join ((48..57) + (97..102) | Get-Random -Count 32 | ForEach-Object {[char]$_})
     ```
   - จะได้ข้อความสุ่ม 32 ตัวอักษร (ตัวเลข+a-f) เช่น `3f9a1c...` ก๊อปค่านั้นไปวางแทนที่ `N8N_ENCRYPTION_KEY=` ในไฟล์ `.env`
8. กด **Ctrl+S** ใน Notepad เพื่อบันทึกไฟล์ `.env` แล้วปิด Notepad

## ขั้นตอนที่ 7: รันระบบด้วย Docker

1. กลับไปที่ PowerShell พิมพ์คำสั่งนี้เพื่อเข้าโฟลเดอร์โปรเจกต์:
   ```
   cd D:\project
   ```
2. พิมพ์คำสั่งนี้เพื่อสตาร์ทระบบทั้งหมด (รวม ngrok):
   ```
   docker compose --profile ngrok up -d
   ```
3. รอสักครู่ (ครั้งแรกจะโหลดโปรแกรมจากอินเทอร์เน็ต อาจใช้เวลา 2-5 นาที) จะเห็นข้อความ `Container ... Started` ทีละบรรทัด
4. ตรวจสอบว่าทำงานครบ 3 ตัว:
   ```
   docker compose ps
   ```
   ต้องเห็น 3 แถว: `tax-advisor-postgres`, `tax-advisor-n8n`, `tax-advisor-ngrok` สถานะ (STATUS) เป็น `Up` หรือ `running` ทั้งหมด

## ขั้นตอนที่ 8: เปิดหน้า n8n และตั้งค่า Postgres Credential

1. เปิดเบราว์เซอร์ ไปที่ http://localhost:5678
2. ครั้งแรกจะเจอหน้า **Set up owner account** (n8n เวอร์ชันปัจจุบันเลิกใช้ Basic Auth แล้ว ใช้หน้านี้แทน) กรอก Email, First Name, Last Name, Password (8 ตัวขึ้นไป มีเลข 1 ตัวและตัวพิมพ์ใหญ่ 1 ตัว) เป็นข้อมูลของคุณเอง แล้วกด **Next** — นี่คือบัญชีที่จะใช้ล็อกอิน n8n ทุกครั้งต่อไป จำอีเมล/รหัสผ่านนี้ไว้ให้ดี
4. คลิกเมนูด้านซ้าย **Credentials**
5. กดปุ่ม **Add Credential** (มุมขวาบน)
6. พิมพ์ค้นหา `Postgres` แล้วเลือก **Postgres**
7. กรอกฟอร์ม:
   - Host: `postgres`
   - Database: `tax_advisor`
   - User: ค่า `POSTGRES_USER` ใน `.env` (ค่าเริ่มต้น `n8n_admin`)
   - Password: ค่า `POSTGRES_PASSWORD` ที่คุณตั้งไว้
   - Port: `5432`
   - SSL: ปล่อยเป็นค่าเริ่มต้น (Disable)
8. กด **Save**
9. ตั้งชื่อ credential เป็น `Tax Advisor Postgres` (คลิกที่ชื่อด้านบนเพื่อแก้)

---

## ขั้นตอนที่ 9: Import Workflow

1. คลิกเมนูด้านซ้าย **Workflows**
2. กดปุ่มลูกศรข้างปุ่ม **Add workflow** (มุมขวาบน) เลือก **Import from File**
3. เลือกไฟล์ `D:\project\n8n\workflows\tax-advisor-workflow.json`
4. workflow จะเปิดขึ้นมาเป็นแผนภาพก้อนๆ ต่อกันเป็นเส้น (เรียกว่า node)
5. หา node สี่ก้อนที่ชื่อ **Upsert User**, **Get Recent History**, **Save User Message**, **Save Assistant Message** (สังเกตสัญลักษณ์ช้าง/ฐานข้อมูล)
6. ดับเบิลคลิกที่ node แรก (**Upsert User**) จะเห็นช่อง **Credential to connect with** เลือก `Tax Advisor Postgres` ที่สร้างไว้ แล้วปิดหน้าต่าง (กดกากบาทมุมขวาบนของ panel)
7. ทำซ้ำขั้นตอนที่ 6 กับอีก 3 node ที่เหลือ
8. กด **Save** (มุมขวาบน หรือ Ctrl+S)
9. กดสวิตช์ **Active** ที่มุมขวาบน (จะเปลี่ยนจากเทาเป็นเขียว) เพื่อเปิดใช้งาน workflow

## ขั้นตอนที่ 10: หา URL ของ ngrok

1. เปิดแท็บใหม่ในเบราว์เซอร์ ไปที่ http://localhost:4040
2. จะเห็นหน้า ngrok Web Interface มีข้อความ **Forwarding** พร้อม URL แบบ `https://xxxx.ngrok-free.app`
3. คัดลอก URL นี้เก็บไว้ (จะยาวประมาณนี้ ไม่ใช่ localhost)

## ขั้นตอนที่ 11: ตั้งค่า Webhook ใน LINE

1. กลับไปที่ https://developers.line.biz/console/ เข้า Channel ของคุณ → แท็บ **Messaging API**
2. หาช่อง **Webhook URL** กด **Edit**
3. ใส่ URL โดยเอา URL จากขั้นตอนที่ 10 มาต่อท้ายด้วย `/webhook/line-webhook`
   ตัวอย่าง: `https://xxxx.ngrok-free.app/webhook/line-webhook`
4. กด **Update**
5. กดปุ่ม **Verify** ข้างๆ ต้องขึ้นเครื่องหมายถูกสีเขียว **Success**
   - ถ้าขึ้น error ให้เช็คว่า workflow ใน n8n เปิด Active อยู่ (ขั้นตอนที่ 9.9) และ container ทั้ง 3 ตัวยังรันอยู่ (`docker compose ps`)

## ขั้นตอนที่ 12: เพิ่มเพื่อนและทดสอบ

1. ยังอยู่ในแท็บ **Messaging API** ของ LINE Developers Console เลื่อนขึ้นไปหา QR Code
2. เปิดแอป LINE ในมือถือ กด **เพิ่มเพื่อน (Add friends)** → **สแกน QR โค้ด (QR code)** แล้วสแกนรูปนั้น
3. เพิ่มเป็นเพื่อนแล้ว เปิดแชทกับบอท พิมพ์ทดสอบ เช่น
   ```
   ค่าลดหย่อนบุตรได้เท่าไหร่
   ```
4. รอ 2-5 วินาที บอทควรตอบกลับมา

### ถ้าบอทไม่ตอบ ให้ตรวจสอบตรงนี้

1. กลับไปที่ n8n (http://localhost:5678) คลิกเมนู **Executions** ด้านซ้าย
2. ดูรายการล่าสุด ถ้ามีสัญลักษณ์กากบาทแดง คลิกเข้าไปดูว่า node ไหน error
3. สาเหตุที่พบบ่อย:
   - node Postgres ยังไม่ได้เลือก credential → กลับไปทำขั้นตอนที่ 9.6-9.7
   - `GEMINI_API_KEY` ผิดหรือหมดโควตา → เช็คในไฟล์ `.env` และดูโควตาที่ https://aistudio.google.com/apikey
   - `LINE_CHANNEL_ACCESS_TOKEN` ผิด → เช็คว่าคัดลอกครบทุกตัวอักษรจากขั้นตอนที่ 4
